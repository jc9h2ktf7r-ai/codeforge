## Что это

CodeForge парсит ваш Python-проект через AST, строит карту файлов / функций / классов и рисует интерактивный граф связей. Всё, чтобы перестать теряться в чужом (или своём старом) коде:

- 🗺️ **Смотреть** — дерево блоков, граф импортов и вызовов, статистика проекта
- 🔍 **Искать** — по именам блоков, docstring, `# ANN:`-комментариям и коду
- ✏️ **Править** — заменять, вставлять, удалять блоки целиком с AST-валидацией и бэкапами
- 💬 **Аннотировать** — привязывать описания «за что отвечает» к блокам (уходят в промпт LLM вместе с графом)

## Ключевые фичи

### 💬 Аннотации — тремя способами

Приоритет при показе: **словарь пользователя → из кода → docstring**.

**1. `# ANN:` — явная аннотация в коде**

```python
# ANN: Парсит файлы проекта, строит дерево блоков и граф связей
def build_project_map(project_dir: Path) -> dict:
    ...
```

**2. Обычный комментарий — подхватывается автоматически**

```python
# Считает отступ строки.
# Понимает табы и пробелы.
def _indent_of(line: str) -> int:
    ...
```

Несколько строк подряд склеиваются в одно описание.

**3. Вкладка АННОТАЦИИ** — без правки кода, хранится отдельно в `data/`.

### 🕸️ Режимы графа

- **СКЕЛЕТ** — только файлы-хабы (>300 строк или ≥4 связей). Так читается большой проект.
- **ПОЛНЫЙ** — все узлы. Для небольших проектов.

### 🛡️ AST-Guard

Любая правка (`replace` / `insert` / `delete`) проверяется на синтаксис **до записи**. Не сошлось — файл не тронут, бэкап сохранён.

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `Ctrl + Shift + F` | Глобальный поиск по коду |
| `Ctrl + F` | Поиск по дереву блоков |
| `Ctrl + S` | Применить изменения в редакторе |
| `Esc` | Закрыть модалки / сбросить фильтр |

## CLI

```bash
# Карта проекта в терминал
python code_map.py list ./my_project

# Статический HTML с картой
python render_map.py ./my_project

# Правка блоков из командной строки
python code_blocks.py get     myfile.py my_func
python code_blocks.py replace myfile.py my_func --from new.py
python code_blocks.py delete  myfile.py old_func
python code_blocks.py backups myfile.py
```

## Структура

```
codeforge/
├── app.py            # FastAPI-сервер: реестр проектов + API
├── code_map.py       # AST-парсер → дерево блоков + граф связей (ноль внешних зависимостей)
├── code_blocks.py    # Атомарные правки блоков (AST-safe, с бэкапами)
├── index.html        # SPA-интерфейс: карта / редактор / аннотации / поиск
├── render_map.py     # CLI: экспорт карты в статический HTML
└── data/             # Аннотации и бэкапы (создаются автоматически)
```
